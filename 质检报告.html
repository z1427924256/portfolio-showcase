严重问题（已全部修复）

严重 敏感信息硬编码并提交至 GitHub
seed.sql

seed.sql 中硬编码了 auth_secret、admin_pass（明文 PBKDF2 哈希）和个人手机号，并已推送到远程仓库，存在凭据泄露风险。

移除所有敏感值，改为占位符 + 注释说明通过 wrangler secret 注入。建议在 GitHub 仓库轮换密钥。
严重 数据库 Schema 与代码不一致
schema.sql · track.js · stats.js

track.js 的 INSERT 语句引用了 ip 和 region_cn 两个字段，但 schema.sql 中 visits 表缺少这两列，导致 INSERT 静默失败，访客数据丢失。

在 schema.sql 中为 visits 表补充 ip TEXT 和 region_cn TEXT 两列，确保 Schema 与代码一致。
严重 上传接口无文件类型验证
functions/api/upload.js

page_image 和 qrcode 上传端点仅检查文件大小（8MB / 4MB），未验证 MIME 类型，攻击者可上传任意文件类型。

添加 /^image\//.test(file.type) 验证，拒绝非图片文件上传。
严重 公开 track 端点无频率限制
functions/api/track.js

/api/track 为公开端点（sendBeacon 调用），无任何频率限制，攻击者可循环请求污染访客数据。

添加基于 CF-Connecting-IP 的频率限制：同一 IP 60 秒内只记录一次访问。

中等问题（已全部修复）

中等 Referrer 数据未写入数据库
functions/api/track.js

前端已上报 ref 字段，但后端代码中缺少 ref 变量定义和 INSERT 绑定，导致来源信息全部丢失。

添加 ref 变量（截断 250 字符）并加入 INSERT 语句的 referrer 字段。
中等 WebP 内容类型检测不完整
functions/api/file/[[path]].js

fixCachedImg 函数只读取流的前一个 chunk 来判断 WebP 魔数，但 WebP 的 RIFF....WEBP 签名跨 12 字节，当首个 chunk 不足 12 字节时会漏判。

改为循环读取并合并 chunk 直到累积 ≥ 12 字节，再做魔数检测。
中等 文件响应缺少安全头
functions/api/file/[[path]].js

页面图片、二维码、PDF 等文件响应未设置 X-Content-Type-Options: nosniff 头，浏览器可能进行 MIME 嗅探。

所有文件响应（200 / 404 / 410）统一添加 X-Content-Type-Options: nosniff 头。
中等 二维码 Content-Type 硬编码为 PNG
functions/api/file/[[path]].js

二维码端点硬编码 Content-Type: image/png，但用户可能上传 JPEG 或 WebP 格式的二维码图片，导致内容类型不匹配。

复用 imgContentType 函数按魔数检测实际格式。
中等 底部 UI 元素缺少磨砂效果
public/index.html

底部水印、电话按钮、二维码按钮未应用 backdrop-filter 磨砂效果，与设计意图不符。

为上述元素添加 backdrop-filter: blur(16px) saturate(1.8) 及 -webkit- 前缀。

低优先级问题（已全部修复）

低 PDF.js 预加载影响首屏性能
public/admin.html

admin.html 在页面加载时同步引入 vendor/pdf.min.js（约 400KB），但 PDF 上传功能仅在用户主动操作时才需要，浪费首屏加载时间。

改为按需懒加载：用户点击「上传替换」时才动态插入 script 标签加载 PDF.js。
低 统计接口无缓存，7 个并发 D1 查询
functions/api/stats.js

每次打开统计页面都并发执行 7 个 D1 查询（总量/今日/本周/按天/按设备/按地区/最近100条），无任何缓存机制。

添加 Worker 实例级内存缓存（30 秒 TTL），命中缓存直接返回，减少 D1 查询压力。
低 频率限制查询缺少 IP 索引
schema.sql · functions/api/track.js

track.js 频率限制查询 WHERE ip=? ORDER BY ts DESC LIMIT 1 无索引支撑，全表扫描。

在 schema.sql 中添加复合索引 idx_visits_ip (ip, ts)。
